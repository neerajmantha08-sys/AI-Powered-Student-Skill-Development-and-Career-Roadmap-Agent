Build a complete, professional, student-friendly web application titled:

**AI-Powered Student Skill Development & Career Roadmap Agent**

This is a BTech academic project. The application must solve a real student problem and must clearly demonstrate the use of an AI Agent and an LLM. It should look like a professional career-development portal, but it must remain simple, clean, understandable, and easy to demonstrate in a college presentation.

Do NOT make this a simple chatbot. The AI Agent must perform a clear multi-step workflow: analyze the student's profile, understand the selected career, identify skill gaps, prioritize the missing skills, create a learning sequence, and recommend suitable projects.

## PROJECT OBJECTIVE

The purpose of the application is to help students understand what skills they need to develop for their desired career.

The student provides:

* Name
* Degree/branch
* Current skills
* Existing projects
* Target career
* Experience level
* Available learning time

The AI Agent then:

1. Analyzes the student's current profile.
2. Determines the important skills associated with the selected career.
3. Compares the student's current skills with the target-career requirements.
4. Identifies skill gaps.
5. Prioritizes the skills that should be learned first.
6. Creates a logical learning roadmap.
7. Suggests practical projects for developing those skills.
8. Produces a personalized career-development plan.

## PROBLEM STATEMENT

Many students are unsure about which skills they need to learn for their desired career. They may know their current skills but often do not know what skills are missing or what they should learn next. This project aims to develop an AI-powered agent that analyzes a student's current skills and career goal, identifies skill gaps, and creates a simple personalized learning and project roadmap to help the student prepare for their desired career.
